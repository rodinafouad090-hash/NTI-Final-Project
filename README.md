NTI Network Infrastructure Final Project
Welcome to the official repository for my National Telecommunication Institute (NTI) Network Infrastructure Final Project. This project demonstrates a comprehensive, enterprise-level network design, configuration, and implementation utilizing Cisco Packet Tracer and modern networking best practices.

📋 Project Overview
This project simulates a multi-tier enterprise network infrastructure designed for scalability, security, redundancy, and high availability. It integrates routing protocols, switching technologies, VLAN segmentation, security configurations, and core network services.

Key Features & Architecture:
Hierarchical Network Design: Structured into Core, Distribution, and Access layers to ensure optimal traffic flow and fault isolation.
VLAN Segmentation: Logical division of departments (e.g., HR, IT, Sales, Management) to enhance security and reduce broadcast domains.
Inter-VLAN Routing: Configured via Layer 3 switches or Router-on-a-Stick to enable communication between different VLANs.
Redundancy & High Availability: Implementation of Spanning Tree Protocol (STP/RSTP/MSTP) and EtherChannel (Link Aggregation) to prevent loops and provide link redundancy.

Routing Protocols: Dynamic routing configured using OSPF/EIGRP to ensure seamless packet delivery across multiple subnets and routers.
Security Measures: Implementation of Access Control Lists (ACLs), Port Security, and secure management access.
Network Services: Integration of DHCP, DNS, and Web servers to support internal clients.
